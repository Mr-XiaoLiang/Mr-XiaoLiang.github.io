# Web Home

这是一个静态的用户主页。设定是用户可以在浏览器打开我的这个页面，然后完成个性化设置，当作自己浏览器里的主页。

它会被部署在 GitHub UserPage 上，以静态网页的形式存在，所有用户个性化数据，都会存在用户浏览器本地。

项目会内置一个 Apps.json 文件，表示内置的一些网站，作为预设应用; Widgets.json 文件，表示内置的一些小部件，作为预设小部件，小部件以 iframe 形式加载在页面上。（这两个文件不要删除或者修改位置，每次GitHub Actions 构建的时候，读取它来生成静态网页的预设APP信息。配置文件的形式方便后期我来添加）

自定义的APP存在于浏览器本地，预设的APP不允许修改，但是允许隐藏或者重新出现，判定的方式是本地存储一个预设APP的开关表，以URL来标记是否显示，没有设置就是显示。

整体的 UI 布局模仿 iPad 的形式，但是需要考虑兼容移动设备和桌面设备。
