小组件接入说明

把一份制作完成的小组件打包为 zip，即可导入 Pop Home 桌面。本文档同时面向人与 AI，可直接复制本页链接发给 AI 学习，由其代为编写小组件。

一、小组件是什么

小组件是渲染在桌面磁块内部的一段可交互内容（例如时钟、搜索框、月历）。每个小组件由一份 manifest.json（声明元数据与尺寸约束）与一份入口代码文件 index.js（导出一个 Vue 组件）组成，二者遵循同一份协议。小组件与框架解耦： 框架只认这两份文件，小组件内部如何实现由作者自行决定，但不得越过下文列出的硬性边界。

二、压缩包结构

把以下内容打包为 .zip（文件可放在压缩包根目录，也可统一放在一个顶层目录内，例如直接压缩小组件文件夹）：

my-widget.zip
├── manifest.json     必填：协议入口，声明元数据与尺寸约束
├── index.js          必填：入口代码文件，默认导出一个小组件模块
└── 其他资源           可选：图片、数据等，运行时通过 assets() 读取
  • 入口文件固定命名为 index.js 或 index.mjs，二者命中其一即可。
  • 入口文件必须是单个自包含的 ES 模块，不得使用相对导入（如 import './util.js'）。
  • 需要打包的资源（图片、JSON 等）通过运行时 assets() 按相对路径读取，详见下文。

三、manifest.json 协议字段

字段 类型 必填 说明
protocol number 是 协议版本，当前必须为 1。
id string 是 全局唯一标识，只能由小写字母、数字、点、下划线、连字符组成，且以字母或数字开头。与内置及既有小组件冲突时导入失败。
name string 是 显示名称，展示在应用库小组件列表中。
description string 是 一句话说明，展示在应用库小组件卡片中。
minSize { cols, rows } 是 最小尺寸（格），作为尺寸下限；cols/rows 均为 1–8 的整数。
defaultSize { cols, rows } 是 默认尺寸，不得小于 minSize。
quickSizes { cols, rows }[] 否 应用库中提供的可选尺寸列表，每一项不得小于 minSize；缺省时仅提供默认尺寸。
hideTileName boolean 否 为 true 时隐藏磁块左下角的名称，默认为 false。
尺寸上限恒由框架统一钳制为 8 格：manifest 只能声明最小尺寸（下限）， 不得声明「上限」字段。超出 8 格或小于 1 格的值在导入校验时会被拒绝。

四、入口文件 index.js

入口文件是一个 ES 模块，默认导出小组件模块。框架兼容以下三种导出形态：

  • export default { component } —— 默认导出 WidgetModule（推荐）。
  • export { component } —— 命名导出组件。
  • export default Component —— 默认导出组件本身。

WidgetModule 的结构：

{
  component: 组件,                    // 必填：用于渲染的 Vue 组件
  defaultProps: { ... },             // 选填：实例默认参数，作为组件 props 传入
}
组件必须从运行时获取 Vue，不得 import 'vue'。入口模块通过全局 globalThis.PopHomeWidget.vue 获取与框架同源的 Vue 运行时，直接 import 'vue' 会引入第二份 Vue 实例，导致响应式失效。运行时接口详见第五节。

五、运行时接口 PopHomeWidget

应用启动时把以下对象挂到全局 PopHomeWidget：

5.1 视图层 PopHomeWidget.vue

提供与框架同源的 Vue 运行时 API：

h, ref, computed, reactive, watch, watchEffect,
onMounted, onBeforeUnmount, nextTick, defineComponent

5.2 资源解析 PopHomeWidget.assets()

返回压缩包资源的解析器，必须在入口模块顶层作用域调用一次（它会捕获当前压缩包的文件表）：

const assets = globalThis.PopHomeWidget.assets();

assets.url('icon.png');   // 返回资源的对象地址（object URL），可用于 <img> 或 fetch
await assets.text('data.json'); // 以 UTF-8 文本读取资源内容

六、开发约束（硬性边界）

  1. 尺寸上限：全局硬上限为 8 格，任何小组件不得突破；minSize 只作下限。
  2. 禁止内部滚动：小组件被装入固定尺寸的磁块容器，容器强制 overflow: hidden；组件自身不得制造可滚动区域，以免抢占用户对桌面的滚动手势。请让内容自适应容器，溢出部分会被裁掉。
  3. 根元素铺满容器：组件的根元素应设 width: 100%; height: 100%，以便充满磁块。
  4. 允许联网：可通过 fetch 请求 API，但仅限静态代码逻辑；框架不提供服务端，也不做数据持久化中转。
  5. 单文件入口：入口文件不得使用相对导入；跨文件复用能力请合并进单个 index.js。
  6. 尺寸自适应：磁块容器已启用容器查询（container-type: size），可在样式中使用 cqw/cqh 单位按容器宽高缩放字号。

七、设计风格建议

本项目遵循 Windows 8 / Windows Phone Metro 视觉语言，小组件应保持一致：

  1. 直角、无圆角：所有色块、按钮、边框一律 border-radius: 0，禁止胶囊、椭圆。
  2. 扁平纯色、无质感：纯色块填充，禁止渐变、阴影、模糊、玻璃拟态。
  3. 高对比、不透明文字：最小字号 11px 且必须不透明，禁止靠降低透明度弱化内容。
  4. 单一强调色：只使用 --accent（#1ba1e2）作选中、焦点与主操作，不多色堆砌。
  5. 字号阶梯：大字号用轻字重，正文 15px、说明 12px，强调用加粗而非更大字号。
  6. 克制动效：入场 250ms ease-out、退场 167ms ease-in，其余交互避免多余动画。

可用 CSS 变量（自动适配明暗主题）

组件渲染在应用 DOM 内，可直接引用以下变量，随主题自动切换：

变量 用途
--flat-text主文字色
--flat-secondary次级文字色
--flat-tertiary弱化说明文字色
--flat-border描边 / 分隔线
--flat-hover悬停 / 底色
--accent强调色（#1ba1e2）
--danger危险 / 错误（#e51400）

八、完整示例

一个可点击累加的「计数器」小组件。

manifest.json

{
  "protocol": 1,
  "id": "my-counter",
  "name": "计数器",
  "description": "点击累加的计数器",
  "minSize": { "cols": 2, "rows": 2 },
  "defaultSize": { "cols": 2, "rows": 2 },
  "quickSizes": [
    { "cols": 2, "rows": 2 },
    { "cols": 3, "rows": 3 }
  ]
}

index.js

const { h, ref } = globalThis.PopHomeWidget.vue;
const assets = globalThis.PopHomeWidget.assets();

export default {
  component: {
    setup() {
      const count = ref(0);
      return () =>
        h('div', {
          style: {
            display: 'flex',
            flexDirection: 'column',
            alignItems: 'center',
            justifyContent: 'center',
            gap: '10px',
            width: '100%',
            height: '100%',
            padding: '12px',
            boxSizing: 'border-box',
            color: 'var(--flat-text)',
          },
        }, [
          h('span', {
            style: { fontSize: 'clamp(18px, 12cqw, 48px)', fontWeight: 700 },
          }, String(count.value)),
          h('button', {
            onClick: () => { count.value += 1; },
            style: {
              border: 'none',
              background: 'var(--accent)',
              color: '#fff',
              padding: '6px 18px',
              fontSize: '12px',
              fontWeight: 600,
              cursor: 'pointer',
            },
          }, '计数 +1'),
        ]);
    },
  },
};

将上述两个文件放入同一目录并压缩为 .zip（文件位于压缩包根目录），即可在桌面「应用库 → 小组件 → 自定义小组件 → 导入小组件」中导入。
